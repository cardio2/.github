# Contributing to Cardio2

Thank you for your interest in Cardio2. This guide explains where to go for each repository.

## Where to write

| Repository | How to take part |
| --- | --- |
| [responsible-ai](https://github.com/cardio2/responsible-ai) | Questions and suggestions about how our AI is designed: open an issue. |
| [cardio2-website](https://github.com/cardio2/cardio2-website) | Typos, broken links, translation errors or display problems on cardio2.info: open an issue or a small pull request. |
| [brand-assets](https://github.com/cardio2/brand-assets) | Issues are closed. To ask about using the logo, email [contact@cardio2.info](mailto:contact@cardio2.info). |
| [.github](https://github.com/cardio2/.github) | Organisation profile and community files. Issues are closed. Email us instead. |

For partnerships, research projects, press or anything else, email [contact@cardio2.info](mailto:contact@cardio2.info).

## Issues

- Search existing issues first.
- One topic per issue, with a clear title.
- For website problems, include the page, the language, your browser and a screenshot if useful.
- Never include real personal or health data. Use invented examples.

## Pull requests

Small pull requests are welcome, for example fixing a typo, a translation or a broken link.

- Keep each pull request focused on one change.
- Explain what you changed and why.
- For larger changes, open an issue first so we can agree on the approach.

## Before you take part

- Read our [Code of conduct](CODE_OF_CONDUCT.md).
- Report security problems privately, as described in [SECURITY.md](SECURITY.md), not in public issues.
